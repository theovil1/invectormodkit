# Security

## Reporting a vulnerability

Please do not open a public issue. Report it privately through
[Report a vulnerability](https://github.com/theovil1/invectormodkit/security/advisories/new) (the Security tab of
this repository). Only the maintainers can read it.

Useful details:

- what is affected (the installer, a plugin, the marketplace, sign-in, leaderboards)
- how to reproduce it, step by step
- what an attacker could do with it

You will get an answer as soon as possible. Please give us time to fix the problem before talking about it publicly.

## Supported versions

Only the latest release receives security fixes. The game offers updates in its main menu, and the installer always
installs the latest version.

## Scope

In scope: the code in this repository, the installer, and the marketplace service the mod talks to (accounts,
publishing, leaderboards).

Out of scope: Invector: Rhythm Galaxy itself, Steam, BepInEx and other third-party components (please report those
to their authors).
